候选区

麦克风

输入设备与录音电平，下一轮录音生效。

按需读取 PulseAudio / PipeWire 的设备列表，不打开麦克风。

手动增益（可选，未校准时的备用设置）

无需先调整这里：自动校准会选择并验证输入增益，匹配设备档案时优先使用校准值。 手动调整会使旧档案失效。数字增益不能消除环境噪声或修复原始录音削波。

麦克风自动校准

保留“系统默认设备”即可，无需手动选麦克风或调增益。程序会识别实际使用的麦克风，自动比较增益及必要的轻度高通。 保持平时的坐姿、距离和音量，先安静三秒，出现朗读提示后再读。请勿刻意提高声音。

同一录音会按少量参数分别送往当前 Portal 识别，并复测和验证，通常产生数分钟识别用量。音频仅在本次任务内存中使用；没有可靠改善时保留当前设置。

新增模型卡

选择来源 → 配置地址和 Key → 刷新并选择模型，或手填兼容模型名称 → 保存。完整配置后才会加入上方列表。

选中文本后按 Alt+Z，说出“翻译为英文”等指令，再按快捷键或 Enter 结束。指令只显示在面板，模型完成后替换原选区。Esc 取消；目标或选区变化时不替换。

仅在选区修改时向当前模型卡发送选区和指令；普通听写只连接 Portal。 DeepSeek 使用官方目录；其他服务使用 OpenAI Chat Completions 兼容格式。不支持选区读取的应用会提示，请用 Shift+Space 听写。

输入与快捷键

与雾凇配合的语音专用模式。

保存后执行 openasrinput start 应用框架选择。自动模式识别运行中的框架，多框架冲突时请手动指定。IBus 启动后执行 ibus engine openasrinput 切换到语音输入源；结束后可切回原输入源。IBus 与 Fcitx5 共用自定义面板；Alt+Z 选区修改需要应用通过输入法提供完整选区，修改前会重新核验目标。

若某些输入框选词后出现“重复重复”，可关闭此选项：普通拼音预览留在候选面板，减少客户端重复提交预编辑的兼容问题。语音预编辑不受影响。保存后立即生效，停止软件后恢复原行为。
